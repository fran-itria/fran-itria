<h2> <b> ¿Quién soy? </b> </h2>

Me encontré con la programacion en 2020 en mi primer año de carrera en Ingenieria Informática y en diciembre finalizo la carrera d Tecnicatura en Desarrollo Webv. <br>
<h2> ¿Que hago? </h2>
Actualmente se inicio el desarrollo de un sistema de gestión de productos, ordenes, usuarios, servicios y cursos para un Estudio de Maquillaje.<br> 
Previamente se finalizo como backend el sistem de gestion de porductos, ordenes, diseños y usuarios de un negocio de venta de productos materos, puliendo mis conocimientos en tecnologías nuevas como Nest.js e incorporando un sistema de pago automático mediante payway, cresium y talo. <br>
Como forntend se realizó la web del administrador para dicha gestión, utilizando Ract junto a TailwindCss. <br>
